Panel de Control Administrativo

Bienvenido al centro de gestión de contenido. Desde aquí podrás supervisar la plataforma y asegurar la calidad de cada publicación.

Protocolo de Administración

Como administrador, tu responsabilidad es mantener el sitio actualizado y ordenado. Para asegurar la mejor experiencia a los usuarios de Noticias Nintendo, seguí estas pautas fundamentales:

  • Respetar las Categorías: Cada noticia debe ir en su lugar. No publiques rumores de Switch 2 en la sección Retro ni viceversa.
  • Portadas de Calidad: Es obligatorio subir una imagen al Storage de Supabase para cada post. Evitá dejar noticias sin imagen.
  • Formato de Texto: Usá el editor para separar párrafos y destacar información. Un post bien escrito se lee mucho más.
  • Moderación de Comentarios: Revisá periódicamente las interacciones para mantener un ambiente sano en la comunidad.
